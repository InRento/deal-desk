## Deploy routine
Source of truth: ~/Desktop/Underwriting tool/deal-desk (from v3.11; v2 is retired). Bump APP_VERSION in src/server.py → ./build.sh → ./run_tests.sh → copy dist/{index.html, server.py, xlsx/jspdf/html2canvas .js} into ~/Desktop/Deal Desk.app/Contents/Resources (deploy.sh does all of it on the Mac) → the user closes the tab and clicks the Dock icon. From the cloud: build in a copy, commit dist files to Resources and changed sources to the deal-desk folder, verify md5 on the Mac. The cloud workspace can be reclaimed between sessions: restore the source from the deal-desk folder before changing anything. New projects: write files to ~/Deal Desk/import/<slug>/ first, JSON last (server ≥ 3.0 imports on next project-list load). When a server bump is also needed, put the import JSON in Deal Desk.app/Contents/Resources/import/ instead – the launcher copies it after restarting the new server.
